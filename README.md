# Vinciane von Westphalen — Website

Statische Website (HTML/CSS, kein Build-Schritt) für Coaching, Supervision & Organisationsberatung.

## Seiten
- `index.html` — Startseite
- `leistungen.html` — Leistungen / Angebot
- `referenzen.html` — Referenzen
- `ueber-mich.html` — Über mich
- `kontakt.html` — Kontakt & FAQ
- `impressum.html`, `datenschutz.html` — Rechtliches (Platzhalter, noch ausfüllen)

## Lokal ansehen
```bash
python3 -m http.server 8000
```
Dann `http://localhost:8000` im Browser öffnen.

## Noch zu ergänzen
- Impressum: Anschrift, Telefon, E-Mail, ggf. Kammer/Aufsichtsbehörde, USt-ID
- Kontakt: echte E-Mail/Telefon; Formular an einen Versanddienst anbinden
- FAQ-Antworten: Entwürfe, von der Auftraggeberin zu bestätigen

Alle redaktionellen Texte stammen aus dem Manuskript „2026_k&h_Website-Texte“.
